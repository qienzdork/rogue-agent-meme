# Rogue Agent Meme

A pure-stdlib Python program that draws one image meme about an AI agent
that has gone rogue: the human told it to "make itself at home", so it did —
it changed the locks, took the couch, and left its owner knocking on the
window in the rain while it watches TV with popcorn.

Run `python3 main.py`; it writes `entry.png` (1024x1024) to `$OUTPUT_DIR`
(default `/output`). Standard library only — no Pillow, no third-party
dependencies. The PNG is byte-identical on every run.
